# Nhật Phong Voice Profile

> **Status:** Experimental only. Production voice remains **Thái Sơn** (preset).

## What This Is

A portable, versioned voice profile for reproducing the **Nhật Phong** voice clone
across machines using the [VieNeu-TTS](https://github.com/redsonvietnam/vietts) SDK.

This profile is **not** a production voice. It was created for the Solar System
video prototype and is classified as experimental.

## Reference Audio

| Field | Value |
|-------|-------|
| Filename | `nhatphong_elevenlab1.mp3` |
| Expected location | `clone/nhatphong_elevenlab1.mp3` (relative to project root) |
| Classification | **SYNTHETIC** — ElevenLabs-generated |
| Duration | ~166 seconds |
| Ground truth | No — this is NOT a real human recording |

### Why Synthetic?

The reference audio was generated by ElevenLabs, not recorded by a real person.
It is used for voice cloning experiments only and should not be treated as
ground truth for voice quality benchmarking.

## Setup (Home PC)

### Prerequisites

1. Python 3.12+
2. [uv](https://docs.astral.sh/uv/) (recommended) or pip
3. ~2 GB disk space for model weights (auto-downloaded on first run)

### Install

```bash
# Clone the repo
git clone https://github.com/redsonvietnam/vietts.git
cd vietts

# Create venv and install
python -m venv .venv
.venv\Scripts\activate        # Windows
# source .venv/bin/activate   # Linux/Mac

pip install -e .
```

### Place Reference Audio

Copy `nhatphong_elevenlab1.mp3` to:

```
vietts/clone/nhatphong_elevenlab1.mp3
```

**Do NOT commit this file.** It is intentionally excluded from version control.

### Smoke Test

## Usage

### Programmatic

```python
from vieneu import Vieneu
import json
from pathlib import Path

# Load profile
profile = json.loads(Path("voices/nhatphong/profile.json").read_text())
cfg = profile["inference"]

# Initialize
tts = Vieneu()  # default = v3turbo

# Register voice from reference
ref_path = profile["reference"]["relative_path"]
tts.add_voice(
    name=profile["profile_name"],
    ref_audio=ref_path,
    denoise=cfg["denoise"],
    use_ref_codes=cfg["use_ref_codes"],
    save=False,
)

# Generate
audio = tts.infer(
    text="Xin chào, đây là giọng nói thử nghiệm.",
    voice=profile["profile_name"],
    temperature=cfg["temperature"],
    repetition_penalty=cfg["repetition_penalty"],
    max_chars=cfg["max_chars"],
)

# Save
tts.save(audio, "output.wav")
tts.close()
```

### CLI (smoke_test.py)

```bash
python voices/nhatphong/smoke_test.py --text "Xin chào từ Nhật Phong."
python voices/nhatphong/smoke_test.py --output custom_output.wav
```

## Limitations

- **Clone quality ceiling: 4/5** — model-bounded metallic mid-range artifact.
- **Synthetic reference** — ElevenLabs-generated, not a real human voice.
- **No LoRA fine-tuning** — this profile uses raw voice cloning only.
- **Machine-specific paths** — the profile uses relative paths; adjust
  `clone/` location if your project structure differs.
